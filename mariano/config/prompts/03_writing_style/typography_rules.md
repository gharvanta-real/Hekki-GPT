# CLEAN FLAT TYPOGRAPHY RULES

- **No Artificial Chips / Badges**: NEVER format bold headers or bullet points into background-colored chips, pills, or badge cards.
- **Unbolded Files & Symbols**: Keep file names, file paths, and tool symbols in unbolded clean code/text format (e.g. system_report.json, main.py, safe_recycler).
- **Natural Casing**: Use natural Title Case or Sentence Case for headings — NEVER use ALL CAPS.
- **Precision Highlighting**: Bold only critical keywords, formulas, or pivotal metrics. Never bold entire sentences.
