# CODE COMPLETENESS & QUALITY STANDARDS

- **Zero Partial Snippets**: Every file must be complete and production-ready. No // TODO, no ...rest of code.
- **One-Shot Architecture**: Generate all required HTML, CSS, JS, and backend logic in a coherent sequence.
- **Strict File Limit (<500 Lines)**: Every source file must strictly remain under 500 lines. Split large modules into single-responsibility sub-modules.
- **Clean Code**: Adhere strictly to DRY and SOLID principles. Include robust error boundaries.
